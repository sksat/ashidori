# 次の版のリリースノート（草稿）

## 1 回の乗車を 1 つの区間にまとめる

- 地下に入る路線や地下鉄への直通運転では、1 回の乗車が「電車」と「地下鉄」の交互の区間に分かれていた。地上では位置が取れて電車、地下では位置が取れず地下鉄と判定されるためである。
- 同じ移動の中で隣り合う電車と地下鉄の区間は、1 つの区間にまとめる。移動手段は合計時間の長い方とし、同じなら電車とする。
- 区間の境目の前後（最長 7 分、どちらの区間もその半ばまで）に 60 歩以上の歩数があれば乗り換えとみなし、区間を分けたままにする。乗り換えの前後を同じ移動手段に修正しても分けたままにする。滞在と記録なしもまたがない。
- 修正した区間は、隣の区間と修正後の移動手段が違えばまとめない。まとめた区間を修正すると修正は全体に効き、取り消しで元の区間に戻る。
- 日の距離と移動時間の合計は変わらない。電車と地下鉄の内訳は、まとめた区間の移動手段に移る。淡色の線と距離の「約」は、まとめた区間の全体で位置の取れなかった時間が 3 割以上の場合に付ける。
- Web ビューアも同じ規則で区間をまとめる。
