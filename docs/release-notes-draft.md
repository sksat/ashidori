# 次の版のリリースノート（草稿）

## 信号機の電波（高度化PICS）の記録

- 設定の「記録」に「信号機の電波を記録」を追加した。既定はオフで、オンにする時に「付近のデバイス」の権限を求める。
- オンの間、記録中に高度化PICS の路側機が送る電波を受信だけして記録する（接続・送信はしない。アプリは接続と送信の権限を持たない）。走査は速さが時速 50 km 以下の間だけ行い、電車・地下鉄・飛行機の区間では行わない。整備交差点の近く（150 m 以内）でだけ走査の頻度を上げ、受信した間だけ受信を続ける。
- ステータスに「信号機」の行を追加した。交差点名（一覧にない交差点は ID）、受信から 2 秒以内の歩行者信号の色、最後の受信の時刻を表示する。
- 端末診断に「信号機の電波」を追加した。権限、Bluetooth、端末の対応、走査の状態、本日の走査時間と受信件数、上限で書かなかった受信、直近 50 行の受信の記録と「受信の試験（60 秒）」を表示する。
- 記録は `pics_adv` 表として、ほかの記録と同じく保存・アーカイブ・暗号化して同期する。記録の状態（`energy_state`）に走査の状態（`ble`）を追加した。データベースは版 10、アーカイブは版 4 になる。
- 警察庁の「全国高度化PICS整備交差点（CSV版）」（令和8年4月1日現在）を加工して APK に含めた。出典は「設定 > データの出典」に表示する。

## ダウンロードの進捗

- 地域・オフライン地図・施設データのダウンロード中は、進捗バーを表示する。表示する場所は「オフラインのデータ」の各行、オフライン地図と施設データのダイアログ、設定の「オフラインのデータ」、地図の案内（オフライン地図なし）。行とダイアログには取得済みの量（例: 12.3 / 45.6 MB）も表示する。
- 大きさがまだ分からない間（スタイルの取得）と、照合・展開の間は、動くバーを表示する。待機中・中断中は状態のみを表示し、バーは出さない。

## 通信のない間のタイムラインの地図

- オンライン地図を自動で使う設定でも、通信のない間は、タイムラインの日の地図をオフライン地図（ダウンロードした基図と地域データ）で描く。これまでは経路だけの絵のまま、地図が出なかった。
- オンライン地図のスタイルを取得できない場合、描画に失敗した場合、30 秒で描き終わらない場合も、同じくオフライン地図で描く。
- 通信が戻ると、オフライン地図で描いたカードを、規則がオンライン地図を自動で使う間だけオンライン地図で描き直す。送信の規則は変えていない。
