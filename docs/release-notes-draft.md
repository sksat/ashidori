# 次の版のリリースノート（草稿）

## ステータスの「信号機」の行

- 「信号機の電波を記録」がオンの間は、ステータスの「信号機」の行を常に表示する。これまでは受信中と受信から 10 分の間だけ表示していた。
- 受信していない間は、走査の状態（待受・便乗・停止）、最寄りの整備交差点までの距離（例: 最寄り 320 m）、当日の最後の受信の時刻と交差点を表示する。
- 「付近のデバイス」の権限がない場合と Bluetooth がオフの場合は、その旨をエラーの色で表示する。行をタップすると、アプリの権限の画面か Bluetooth の設定を開く。
- 受信中の表示（交差点名と、受信から 2 秒以内の歩行者信号の色）は変わらない。最後の受信の時刻は 2 行目に移した。
