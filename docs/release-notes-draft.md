# 次の版のリリースノート（草稿）

## ダウンロードの進捗

- 地域・オフライン地図・施設データのダウンロード中は、進捗バーを表示する。表示する場所は「オフラインのデータ」の各行、オフライン地図と施設データのダイアログ、設定の「オフラインのデータ」、地図の案内（オフライン地図なし）。行とダイアログには取得済みの量（例: 12.3 / 45.6 MB）も表示する。
- 大きさがまだ分からない間（スタイルの取得）と、照合・展開の間は、動くバーを表示する。待機中・中断中は状態のみを表示し、バーは出さない。

## 通信のない間のタイムラインの地図

- オンライン地図を自動で使う設定でも、通信のない間は、タイムラインの日の地図をオフライン地図（ダウンロードした基図と地域データ）で描く。これまでは経路だけの絵のまま、地図が出なかった。
- オンライン地図のスタイルを取得できない場合、描画に失敗した場合、30 秒で描き終わらない場合も、同じくオフライン地図で描く。
- 通信が戻ると、オフライン地図で描いたカードを、規則がオンライン地図を自動で使う間だけオンライン地図で描き直す。送信の規則は変えていない。
